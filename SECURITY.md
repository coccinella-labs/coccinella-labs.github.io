# Security Policy

coccinella-labs takes security seriously. Every project in the collection follows
the policies described here.

## Reporting a vulnerability

Please report vulnerabilities **privately** instead of opening a public issue.

- Use our security contact: <https://coccinella-labs.github.io/.well-known/security.txt>
- Or open a private security advisory:
  <https://github.com/coccinella-labs/coccinella-labs.github.io/security/advisories/new>

Please include:

- A description of the issue and where it occurs
- Steps to reproduce
- The affected project and version, if known

You should receive a response within a few days. Please do not disclose the
issue publicly until it has been addressed.

## Supported versions

Only the latest published release of each project is supported. Security fixes
are shipped in the next release.

## Security.txt

The machine-readable security contact lives at
`/.well-known/security.txt` on the website and is also served from this
repository at `public/.well-known/security.txt`. Keep both files in sync when
contact details change.
