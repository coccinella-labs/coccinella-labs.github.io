gpucomm fs

Binary-aware artifact store and filesystem foundation for gpucomm (GPU artifacts, datasets, weights).

Rust·Library·Stable·MITRepository ↗

Overview

A content-addressed store for large GPU artifacts: datasets, weights, and cubin or PTX bundles. The v0 CLI initializes a store and puts, lists, and gets files, recording metadata alongside each object for search and reproducibility.

Installation

cargo install --git https://github.com/coccinella-labs/gpucomm-fs
